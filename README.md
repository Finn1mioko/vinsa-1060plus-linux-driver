# VINSA T501 Linux Driver

Userspace-драйвер для графического планшета VINSA 1060 Plus / T501.

Драйвер работает через USB и создаёт в Linux стандартные input/uinput-устройства для пера, кнопок и колеса.

> **Важно:** проект находится в экспериментальном состоянии. Большая часть кода драйвера была написана с помощью ИИ и затем проверена на реальном устройстве. В проверенных сценариях драйвер работает хорошо, однако стабильность и корректная работа на всех системах и конфигурациях не гарантируются.

## Поддерживаемое устройство

USB:

* Vendor ID: `08f2`
* Product ID: `6811`

Проверить устройство можно командой:

```bash
lsusb -nn
```

Ожидаемый USB ID:

```text
08f2:6811
```

## Что работает

На текущий момент основной функционал планшета работает штатно:

* перо и координаты;
* давление пера;
* кнопки пера;
* кнопки планшета;
* назначенные клавиши и действия;
* автоматическая настройка устройства;
* медиа-панель устройства;


## Установка

Распакуйте архив:

```bash
tar -xzf vinsa-t501-0.1.0.tar.gz
```

Перейдите в каталог:

```bash
cd vinsa-t501-0.1.0
```

Запустите установщик:

```bash
sudo ./install.sh
```

Установщик:

1. устанавливает необходимые системные зависимости;
2. создаёт отдельное Python virtualenv;
3. устанавливает `pyusb` и `evdev`;
4. устанавливает драйвер;
5. устанавливает udev rule;
6. устанавливает systemd service;
7. включает автоматический запуск драйвера.

После установки сервис запускается автоматически.

## Проверка

Показать статус:

```bash
sudo systemctl status vinsa-t501
```

Посмотреть журнал драйвера:

```bash
sudo journalctl -u vinsa-t501 -f
```

## Ручной запуск

Для диагностики можно остановить сервис:

```bash
sudo systemctl stop vinsa-t501
```

И запустить драйвер вручную:

```bash
sudo /usr/local/bin/vinsa-t501 --debug
```

Также доступны аргументы, которые поддерживает сам `driver.py`, например:

```bash
sudo /usr/local/bin/vinsa-t501 --debug
sudo /usr/local/bin/vinsa-t501 --raw
```

## Автозапуск

После установки сервис включён в автозапуск.

Отключить автозапуск:

```bash
sudo systemctl disable vinsa-t501
```

Остановить:

```bash
sudo systemctl stop vinsa-t501
```

Снова включить:

```bash
sudo systemctl enable --now vinsa-t501
```

## Удаление

Из каталога распакованного архива:

```bash
sudo ./uninstall.sh
```

Удаляются:

```text
/opt/vinsa-t501/
/usr/local/bin/vinsa-t501
/etc/systemd/system/vinsa-t501.service
/etc/udev/rules.d/70-vinsa-t501.rules
```

Модуль ядра `uinput` специально не выгружается.

## Если планшет не работает

Сначала проверьте, определяется ли устройство:

```bash
lsusb -nn
```

Затем проверьте сервис:

```bash
sudo systemctl status vinsa-t501
```

И журнал:

```bash
sudo journalctl -u vinsa-t501 -n 100 --no-pager
```

Проверьте наличие `uinput`:

```bash
ls -l /dev/uinput
```

При необходимости:

```bash
sudo modprobe uinput
```

После этого перезапустите сервис:

```bash
sudo systemctl restart vinsa-t501
```

## Важное замечание

Это userspace-драйвер. Он не является модулем ядра Linux.

Во время работы драйвер выполняет USB reset и отсоединяет некоторые kernel USB interfaces устройства перед настройкой планшета. Поэтому при разработке и диагностике желательно иметь возможность отключить и снова подключить планшет по USB.

Поведение драйвера рассчитано на протокол устройства `08f2:6811`. Наличие такого же USB ID у другого устройства само по себе не гарантирует совместимость.

## Состояние проекта

Этот проект создаётся прежде всего для того, чтобы сделать планшет работоспособным в Linux без официального полноценного драйвера.

Код развивается постепенно. Возможны:

* ошибки;
* зависания;
* необходимость перезапуска драйвера;
* различия в поведении между дистрибутивами Linux;
* изменения протокола и внутренней реализации в следующих версиях.

Несмотря на это, основные функции уже проверены на реальном устройстве и в проверенных сценариях работают нормально.

При обнаружении проблем рекомендуется сохранять вывод:

```bash
sudo journalctl -u vinsa-t501 -n 200 --no-pager
```

и по возможности использовать запуск с:

```bash
sudo /usr/local/bin/vinsa-t501 --debug
```
